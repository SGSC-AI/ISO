# 目的

> 為使網路環境得以確保傳輸安全性，使網路正常運作，特制定本程序。

# 範圍

> 所有內部網路及對外聯網之設備；及相關人員的網路活動，均適用本程序。

# 權責

## 資安長

> 本辦法文件發行之審查與核准。

## 文管中心

> 文件之製作、審查、發行、修訂、更新及保管。

## 資訊室

> 本辦法製作與協調各部門落實實施相關措施、要求。

## 相關單位

### 網路使用者:即提出網路存取使用需求之人員。

### 系統管理者

- 分析系統與應用程式之網路存取行為，提供防火牆設定之參考資訊。

- 負責提供網路存取行為相關容量數據，提供防火牆配置之參考資訊。

### 資訊室主管

- 審核防火牆開放與限制之申請。

- 監督防火牆管理作業。

- 使用防火牆產品之審核。

### 防火牆系統管理者

- 防火牆之建置、管理與維護。

- 使用防火牆產品評估建議。

# 定義

## WAF(Web Application Firewall)

> 即網站應用程式防火牆，WAF主要用於保護網站應用程式，透過監控網站傳輸的HTTP流量，保護網站免受攻擊。

## DMZ（Demilitarized Zone）

> 連接防火牆上的特殊區域，用以區隔組織對外與對內提供服務之網路區域。

## ACL

### 防火牆規則正面表列：依允許進入的方式作存取控制，其內定設定為禁止。

### 防火牆規則負面表列：依禁止進入的方式作存取控制，其內定設定為開放。

# 作業程序

## 網路安全認知宣導

### 網路資源須經授權方可使用，已授權的使用者，僅能在授權範圍內存取網路資源。

### 使用者不得將自己的登入帳號與密碼交付他人使用，亦不得以任何方法竊取他人的帳號密碼。

### 使用者禁止以任何儀器設備或軟體工具竊聽網路上的通訊，亦不得以任何手段干擾網路正常運作。

### 如使用瀏覽器應先評估所瀏覽網頁之安全性，並考慮瀏覽器安全性設定以降低網路連線風險發生。

### 「機敏」等級資訊檔案傳送需設定密碼保護，避免重要資訊經由網路外洩，應限制使用者之網路存取權限以確保網路傳輸安全。

### 各電腦或筆電於使用時，應安裝防毒軟體，防毒軟體應定期更新，並且不得關閉防毒軟體自動掃毒之功能。

### 使用可攜式設備或儲存媒體，必須先進行掃毒以免受惡意程式威脅，禁止開啟來路不明電子郵件及其附加檔案。

### 電腦與主機使用者應將重要資料定期備份。

### 如遇惡意程式感染情況，防毒軟體無法處理或作業仍不正常時，使用者應立即通報資訊室專人處理，資訊室應判斷感染途徑及其惡意程式名稱，協助使用者將惡意程式移除或隔離。

## 網路架構規劃

### 管理代表應審查網路架構圖與防火牆政策，每年應定期至少檢視一次是否有風險升高之情事可能發生，並適時調整、維護及更新防火牆政策作為因應。防火牆設定原則可考量下列事項：

- 限制來自任何網路對防火牆管理的連線，並以此作為防火牆之基本過濾原則，除由指定IP及特定的連接埠登入管理外，非系統管理者、防火牆系統管理者均不能連接管理防火牆。

- 應避免以過大範圍之群組設定來源或目標位址和協定。

- 優先考慮使用正面表列，並應於規則最後設置拒絕全部服務的規則(Implicit Denied All)，以預防因前述規則的疏漏，導致來自網際網路之入侵與非法連線，盡可能採取網路黑名單之設定，避免產生防火牆於網路防護上之漏洞與風險。

- 防火牆規則設定完成後，應進行防火牆規則參數之組態檔案(Config)備份，並定期檢查防火牆規則參數未被竄改，該備份檔案依「ISP-07資訊備份管理程序」規定保留。

### 防火牆政策可登載於「防火牆ACL管制表」或於防火牆控制台(Console)上進行管控，管理者應每半年或變動時進行防火牆政策之審查。

### 內部網路之使用，應對使用狀況與條件區分不同網路區段，以便進行網路存取管控，各區段應以特定的安全設施(如：防火牆及網路閘門)加以保護，以降低於同網域發生惡意程式橫向感染之風險。例如:

- Guest區域不得連線內部網路；

- <span class="mark">測試區與正式區應採不同網段；</span>

- 除非有補償性控制措施，否則外部網路不得連線到機敏資料儲存區。

### 資訊室應派專人管控【網路服務功能與通訊協定】，當通訊協定需異動時，資訊室主管應進行安全評估，確定可行且無安全顧慮後，<span class="mark">於系統上進行防火牆連線服務異動申請</span>。

## 技術性遵循查核

### 為確保各項資訊系統能持續提供穩定服務，必要時應採取弱點掃描方式以找出各項系統潛在弱點、威脅的風險。

### 應定期針對核心業務系統(例如伺服器)實施弱點掃描作業，實施弱點掃描後，【弱點掃描報告】(得以弱掃軟體工具報表代替)顯示高風險(即顯示Critical或High)進行弱點修補，中低以下風險(即顯示Medium、Low或Information)採取接受風險。

### 資訊室應針對弱點修補情形記錄於「重大弱點補強紀錄表」以做為鑑別追溯。

## 線路與傳輸安全

### 網路通訊設備於安裝時，應注意機房之電力線路架構，應執行網電線路區隔，以防相互干擾，易遭受破壞之線路(如光纖)設施應妥善保護，以免因其他工程裝設而影響網路之運作，線路如有異動，須經由專責人員執行。

### 網路通訊設備安裝應考慮裝置場地之安全性，儘可能設置於有門禁管制之地點，並考慮電力穩定、通風散熱問題，重要網路通訊設備應採用不斷電系統以穩定電力。

### 網際網路應用系統所提供各項服務，若涉及機密資料存取，應啟動安全之加密防護機制（如：VPN、SSL等），以確保資料安全及未經授權的揭露與修改。

### 資訊室應進行網路流量之監控，以保障網路頻寬正常使用，如發現長時間的網路流量異常，應立即分析網路異常原因並採取適當之矯正措施，並將結果記錄備查。

### 網路通訊設備於安裝上線前，應進行安全與作業影響評估，並考慮是否請供應商提供到場協助，資訊室應派員全程陪同監控，供應商如有遠端測試需求，應由資安長核准後辦理，相關作業依「ISP-12資訊作業委外管理程序」辦理。

## 組態管理

### <span class="mark">管理者應將重要設施(重要主機與儲存裝置)盤查並登載其軟體組態版本於「資訊資產清冊」。</span>

### <span class="mark">當該組態有重大變更時，管理者應進行必要之審查，確認其必要性後實施，變更前應填具「軟體安裝記錄表」。</span>

### <span class="mark">管理者應將重要設施(重要主機與儲存裝置)依據「系統主機安全檢查表」之安全要求設定重要設施之安全組態，每半年至少檢查一次，以確保重要設施(重要主機與儲存裝置)之安全組態設定值未被惡意變更或竄改。</span>

### <span class="mark">為避免安全組態發生未被授權之變更，應管控特權帳號或系統管理者權限之帳號數量，並且停用非必要(未使用或不安全)之特權帳號、系統管理者帳號。</span>

### <span class="mark">管理者可參考公開可取得之指引或原廠之建議方式，將重要設施(重要主機與儲存裝置)之安全組態進行優化，以避免潛在風險發生。</span>

## 網頁過濾

### <span class="mark">資訊室應進行必要之宣導，以避免同仁存取含有非法資訊或已知含有病毒或網路釣魚風險之網站。</span>

### <span class="mark">管理者應於防火牆或防毒軟體採取設定黑名單之方式封鎖相關網站IP位址或網域。</span>

### <span class="mark">網頁過濾黑名單之設定，應保持最新狀態，可參考下列原則：</span>

- <span class="mark">已知或可疑之惡意網站(例如賭博、色情、散布惡意軟體或釣魚網站)。</span>

- <span class="mark">由已收集資安情資中之惡意網站。</span>

- <span class="mark">分享非法內容之網站(例如違反智慧財產權或個資法之不良內容著作或影片)。</span>

- <span class="mark">本控制措施應用最洽當之方式對同仁宣導，各單位如有任何基於合法營運理由而需存取受限網站資源時，應提出權限申請，經資安長放行後才能由管理者開通使用者進行瀏覽。</span>

## 端點監控

### <span class="mark">管理者可使用防火牆或防毒軟體之功能監控必要之潛在風險。</span>

- <span class="mark">藉由檢視設施(重要主機與儲存裝置)存取狀況，檢視是否有潛在風險發生。</span>

- <span class="mark">藉由每半年實施之「系統主機安全檢查表系統主機安全檢查表」檢視設施(重要主機與儲存裝置)之組態設定是否被竄改，以避免潛在風險。</span>

- <span class="mark">檢視設施(重要主機與儲存裝置)等日誌檔案，確保無相關之異常情況。</span>

- <span class="mark">檢視重要程式碼未遭竄改。</span>

- <span class="mark">檢視資源為正常使用與運作狀態(如：CPU、硬碟、記憶體、頻寬流量等)。</span>

### <span class="mark">端點檢查應評估正常行為之基準，確認系統於正常時期及尖峰時期之使用率之狀況；以及各使用者之平常存取時間、存取位置及存取頻率之習慣，是否發生異常之情形，當發生時，管理者應採取必要之管控，以避免潛在風險。</span>

### <span class="mark">常見之端點監控異常行為：</span>

- <span class="mark">已知惡意IP位址或網路網域之惡意軟體或典型活動(如：與殭屍網路之指揮控制伺服器相關聯的活動)。</span>

- <span class="mark">已知之攻擊特性(如：阻絕服務及緩存區溢位)。</span>

- <span class="mark">異常系統行為(如：按鍵存錄、過程注入及標準協定之使用偏差)。</span>

- <span class="mark">對受保護資源(如：DNS伺服器、入口網站入口網站及檔案系統)之成功及未成功嘗試存取。</span>

### <span class="mark">管理者應定期進行「個人電腦安全檢查表」之電腦端點檢查，當發現異常時，應進行必要之回應處理。</span>
