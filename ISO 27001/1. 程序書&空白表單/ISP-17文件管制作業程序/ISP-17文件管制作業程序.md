# 目的

為使本公司資安管理系統文件之製作、審查、修訂、發行、作廢等作業有所依據，特訂本作業辦法。

# 範圍

凡有關於資安管理系統之文件與資料皆適用之。

# 權責

## 資安長

本辦法文件發行之審查與核准。

## 文管中心

文件之製作、審查、發行、修訂、更新及保管。

## 資訊室

本辦法製作與協調各部門落實實施相關措施、要求。

## 相關單位

協助文管中心執行並推動製、審、修、發、廢等作業。

# 定義

## 文件

本公司書面化或電腦化文件、表單與資料之統稱。

## 第一階文件

泛指各系統之手冊類文件，僅說明公司管理系統執行之架構及方向，如：資安手冊等文件。

## 第二階文件

泛指各手冊所提及之程序、辦法文件，詳細說明公司管理系統執行之框架、內容及步驟，如：資料檔案管制作業程序。

## 第三階文件

無法在程序、辦法內詳細說明之工作內容或步驟，需另編詳細資料以利作業進行，如：資安風險量化評鑑作業指導書。

## 第四階文件

- 將執行資安作業之結果記錄並保留之憑證，如：員工保密切結書等。

- 第四階文件可以用電子媒體、光碟片、照片、公告等方式呈現。

## 智慧財產權

由著作權法規範之各種之IP、軟體、圖面、技術資料、規格標準、授權書或任何檔案記錄等資料，包含網際網路上傳送之各式電腦檔案。

## 外來文件

自外部取得之技術、規格資料或國際標準等。

## 管制文件

資安管理系統有關之各文件皆屬管制文件。

## 文件製作

- 依公司流程必要或狀況需求，單位主管可以參考本程序的製作模式、架構，自行製作各種管制文件。

文件製作格式可參考本程序之階層架構展開，其餘要求如下：

- 文件用紙：一般A4紙張。

- 辦法類文件階層架構需依下列要項書寫。

1.  目的。

2.  範圍。

3.  權責。

4.  定義。

5.  作業程序。

6.  使用表單。

7.  附件。

- 手冊類文件架構展開請參考資訊安全政策規定辦理。

- 適用性聲明書架構展開請依據適用性聲明書需求制定。

## 審查作業

- 文件製作完成後，製作人將電子檔或紙本文件交由文管中心，文件管制人員接收送審文件後，需先行檢視文件架構及格式是否恰當。

- 格式無誤後，文件管制人員將文件進行編號；以及填具「文件制修訂申請單」與正稿文件一併交各單位代表審查會簽。

- 文件經會簽後，如無其它單位意見需增修，則由文件管制人員逕行送權責人員核准。

### 各階文件簽核權限如下表

|      |            |              |              |
|------|------------|--------------|--------------|
|      | 一階文件   | 二階文件     | 三、四階文件 |
| 制定 | 資訊單位   | 各單位承辦人 | 各單位承辦人 |
| 審查 | 管理代表   | 單位主管     | ---          |
| 核准 | 資安長     | 管理代表     | 單位主管     |
| 保管 | 各部門主管 | 各部門主管   | 各部門       |
| 發行 | 文管中心   | 文管中心     | 文管中心     |

## 發行作業

- 文件經權責人員核准後即可發行，發行公佈日期即為生效日期。

- 文件管制人員於文件發行前，需以正本文件印製副本，再於封面加蓋有「文件管制」之註記，以資鑑別。

- 新發行文件為第1.0版，如變更時以2、3、4…阿拉伯數字順序變更之。

- 文件如採取紙本形式發行後，文件管制人員需將收發資料登錄於「文件分發記錄」，予以列管。

## 修訂作業

### 定期修訂

文件之適用性可於每次內部資安稽核後，由相關權責人員做適當考量，進行變更。

### 非定期修訂

當實際作業狀況變更後，相關權責人員得隨時進行變更。

- 為清楚記錄文件變更部份，相關權責人員需填具「文件制修訂申請單」隨修訂文件附上並送審，修訂作業之步驟同製作作業流程。

- 文件如需變更，需由原製作審核之權責單位進行作業，如原權責單位人員已經異動，接辦該項業務者，可查閱過去製修訂歷史資料做為修改依據。

## 保管作業

- 管制文件需由使用單位自行保管，單位主管為必然之保管人，單位主管亦可指派人員進行文件管制作業。

- 職務異動時，管制文件列為交接項目。

- 文件管制中心需將所有文件之相關資訊記錄於「文件總覽表」以清楚表示文件管制狀態及版本發行狀況，且該表必需適時更新資訊以資鑑別。

## 廢止、回收、銷燬作業

- 作廢後之文件，其文件原稿需註明「舊版」字樣，其原稿需保存一年後銷毀。

- 文件收發需由文件管制人員執行文件交換作業，過期文件如有其他用途保存，應標示該項用途。

- 作廢之文件可以絞碎等方式處理。

## 文件申請作業

當文件有遺失、破損、髒污、增補等狀況時，需求單位主管需以內部聯絡單說明原因，再送文件管制中心辦理。

## 外來文件之管制

- 文件管制人員於外來文件發行前，需於正本文件封面或第一頁標明「外來文件」字樣之註記，以資鑑別。

- 外來文件如有發行紙本形式文件之必要，文件管制人員需將收發資料登錄於「文件分發記錄表」，予以列管。

## 記錄管理

### 內部記錄管理

- 資安記錄之存放應置於適當之場所，以避免損壞或變質。

- 對於具有機密性的資安記錄應委善保管，以防止人為損壞。

- 資安記錄、檔案應自定保存年限，超過保存年限內者，應視需要予以銷毀。

- 該保存期限應登錄於「文件總覽表」並由各單位自行保管。

### 供應商之資安記錄

- 供應商維護之資安記錄，必要時應建檔保存。

- 涉及商業機密足以影響廠商營運之相關記錄，不得對外洩露，非經許可不得複印、攜出。

- 相關資訊類資產機密等級之標示方式請參考「資料檔案管制作業程序」。
